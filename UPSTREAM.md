# Upstream issue tracking (Tencent/xLua and forks)

This file records which upstream Tencent/xLua issues, pull requests and fork
commits were checked against xLua-NG and what was found, so they are not
re-checked. It is a list of findings, not a roadmap; planned work goes in
[ROADMAP.md](ROADMAP.md).

- Base: xLua-NG contains every upstream commit up to 59bf426 (Tencent/xLua
  master, 2025-11-21, #1208).
- Scope of the 2026-10-16 pass: open upstream issues back to 2019 (those that
  look like real bugs), closed issues since 2022, open and unmerged closed
  pull requests since 2021, and the 149 forks pushed since 2023-06 (compared
  with `gh api repos/Tencent/xLua/compare/master...OWNER:REPO:BRANCH`).
- Status values: fixed, present, not applicable, unknown, won't fix.
  "present" means the bug was traced in the code but not reproduced. Rows
  that need a test say so.
- How to update: when you fix, test or re-check an item, edit its row,
  put a commit sha or file:line in Evidence and set Last checked. Add new
  upstream items in priority order, then by number. Sweep upstream again with
  `gh issue list -R Tencent/xLua --state all --search "updated:>YYYY-MM-DD"`
  and compare it with this table.
