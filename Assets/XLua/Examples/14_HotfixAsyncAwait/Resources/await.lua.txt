--- Emulate the C# [await](https://learn.microsoft.com/dotnet/csharp/language-reference/operators/await) keyword
---
---@param awaitable any An asynchronous task or an object with a GetAwaiter method. See the C# awaitable documentation [reference](https://learn.microsoft.com/dotnet/csharp/asynchronous-programming/async-return-types#generalized-async-return-types-and-valuetasktresult)
---@param continuation function Continuation function. Wrap the code that would follow await in C# in a callback to run when the task completes. [Reference](https://learn.microsoft.com/dotnet/api/system.runtime.compilerservices.taskawaiter-1.unsafeoncompleted)
function await(awaitable, continuation)
    local awaiter = awaitable:GetAwaiter()
    if awaiter.IsCompleted then
        --If already completed, invoke the continuation directly.
        local result = awaiter:GetResult()
        continuation(result)
    else
        --Otherwise, register the continuation with the asynchronous task.
        awaiter:UnsafeOnCompleted(function ()
            local result = awaiter:GetResult()
            continuation(result)
        end)
    end
end
